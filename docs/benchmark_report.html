4. 方法说明

  • FastBrain：事件驱动突触块压缩 + CUDA Graph 整段录制回放；dt=0.25 ms 为实时模式。
  • n_run 为顺序独立试次，每试次重建实例（CUDA Graph 持有 RNG 状态），与 Brian2GeNN 后端约定一致。
  • 脉冲导出在计时区外完成；sim 列仅含图回放。
  • 本机 Brian2 CPU 缺席（VS 2022 缺 C++ 工作负载），ground-truth 对比待 Linux/WSL2 环境补齐。
数据文件：data/results/local_fastbrain/（spike parquet + pairwise 对比）， experiments/out/validation/（验证矩阵 CSV/JSON）。仓库： github.com/ArcadiaE/fly-brain（fork of eonsystemspbc/fly-brain）。
