概述。本项目在消费级 GPU 上实时运行果蝇全脑 LIF 模型（Shiu et al. 2024，Nature），核心是自研的 FastBrain 事件驱动引擎：突触块压缩 + CUDA Graph 整段回放，在 RTX 3060 Laptop（6 GB 显存）上达到 1 倍实时，精度与参考实现的差异等于随机种子噪声。仓库为 eonsystemspbc/fly-brain 的研究分支，新增 FastBrain 引擎、实时交互控制台、3D 回放与系统验证体系，并把 FastBrain 接入官方基准成为第 7 个后端。

Overview. This project runs the whole-brain Drosophila LIF model (Shiu et al. 2024) in real time on consumer GPUs. Its core is FastBrain, an event-driven engine (synapse-block compression + whole-graph CUDA Graph replay) reaching 1× real-time on an RTX 3060 Laptop (6 GB), with accuracy indistinguishable from reference seed noise. This repo is a research fork of eonsystemspbc/fly-brain, adding the engine, an interactive live console, offline 3D replay, a systematic validation harness, and a 7th benchmark backend.

模型与数据Model & Data

模型。渗漏积分发放（LIF）点神经元 + alpha 突触，dt = 0.1 ms（实时模式 dt = 0.25 ms），权重由 FlyWire v783 连接组突触数导出，递质符号来自递质预测。支持任意神经元集合的泊松激活（光遗传式）与沉默。蘑菇体学习相关细胞已在注释中核实：5,177 个 Kenyon 细胞（11 类）、96 个 MBON（35 型）、331 个多巴胺能神经元（PAM/PPL 27 型）。

Model. Leaky integrate-and-fire point neurons with alpha synapses at dt = 0.1 ms (0.25 ms in real-time mode); weights derived from FlyWire v783 synapse counts, signs from predicted neurotransmitters. Arbitrary neuron sets can be Poisson-activated (optogenetic-style) or silenced. Mushroom-body learning circuitry verified in annotations: 5,177 Kenyon cells (11 types), 96 MBONs (35 types), 331 dopaminergic neurons (27 PAM/PPL types).

FastBrain 引擎The FastBrain Engine

设计。原版 PyTorch 后端每步做一次稠密 SpMV，仅 0.1 倍实时；诊断表明瓶颈是每步约 75 个 CUDA kernel 的启动开销。FastBrain 的方案：① 事件驱动——WT 切成 256 宽定长突触块（15.1 万块），每步用 cumsum 压缩把放电神经元的块装入固定槽位，gather + index_add 替代全图乘法；② 全张量定形，整块 S 步录成一张 CUDA Graph 一次启动，每步内核数从 ~75 降到 ~33；③ 延迟环取延迟步数整数倍，环槽位成为编译期常量；④ 脉冲导出复用压缩后的活动块列表。显存占用约 0.45 GB。

Design. The stock PyTorch backend runs one dense SpMV per step at ~0.1× real-time; profiling showed the bottleneck is kernel-launch overhead (~75 kernels/step). FastBrain instead: (1) event-driven propagation — WT is cut into 256-wide fixed-size synapse blocks (151k blocks); each step a cumsum compaction packs the blocks of spiking neurons into fixed slots, then gather + index_add replaces full-graph multiplication; (2) all tensors are shape-pinned so S whole steps are captured into one CUDA Graph launched once, cutting kernels from ~75 to ~33 per step; (3) the delay ring length is a multiple of the delay in steps, making ring slots compile-time constants; (4) spike export reuses the compacted active-block list. Memory: ~0.45 GB.
